6. Intro chào mừng (tùy chọn)

Bản mẫu chưa tạo giọng AI tự động. Muốn có giọng nữ lớn tuổi, thanh lịch, cần kết nối dịch vụ tạo giọng nói/TTS và lưu file âm thanh hoặc tích hợp API khi triển khai.

Lưu ý về tên miền riêng: bản mẫu này chưa tự xuất bản lên Internet. Để dùng tên miền riêng và cập nhật website công khai, cần đưa các file lên dịch vụ hosting và kết nối tên miền. Cài đặt và trang chính phải dùng cùng một hệ thống lưu dữ liệu (ví dụ cơ sở dữ liệu/API) nếu muốn cập nhật trực tuyến từ mọi thiết bị.
